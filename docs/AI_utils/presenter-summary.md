# 발표자용 AI 기능 요약

여행WON해의 AI는 **지출을 기록할 때 → 소비를 돌아볼 때 → 다음 구매를 선택할 때**의 불편을 돕습니다.

| AI 기능·사용 위치 | 왜 필요한가요? — 사용자의 불편 | AI가 하는 일 | 어떤 점이 편해지나요? |
| --- | --- | --- | --- |
| **영수증 자동 정리** · PAGE 1 | 외국어 영수증을 해석하고 매장·상품·금액을 일일이 입력하기 번거로움 | 사진에서 매장·날짜·상품별 수량과 가격을 읽고, 한국어 이름과 소비 분류를 정리 | 사용자는 채워진 내역을 확인·수정해 저장하므로 기록 부담을 줄일 수 있음 |
| **소비 인사이트** · PAGE 1 | 차트만 보고는 예산을 빨리 쓰는지, 앞으로 하루에 얼마를 써야 할지 판단하기 어려움 | 프로그램이 계산한 예산 사용 속도·예상 지출·남은 하루 예산·다른 여행 기록과의 차이를 쉬운 문장으로 설명 | 현재 소비 상황을 이해하고 남은 여행의 지출 계획을 세우는 데 도움 |
| **예산 맞춤 상품·매장 추천** · PAGE 2 | 가격·거리·구매 기록을 매장마다 비교하고 내 예산에 맞는 선택을 찾기 번거로움 | 프로그램이 점수화한 상위 10개 후보 중 최대 3개를 고르고, 남은 예산과 소비 성향을 고려한 추천 이유를 설명 | 여러 조건을 함께 고려한 구매 후보를 빠르게 살펴보고 선택할 수 있음 |

| 발표 중 받을 수 있는 질문 | 짧은 답변 |
| --- | --- |
| **왜 AI를 썼나요?** | 외국어 영수증을 읽고 정리하거나, 여러 구매 조건을 함께 고려하고 이유를 자연스럽게 설명하는 데 활용했습니다. |
| **금액 계산도 AI가 하나요?** | 금액·거리·예산·비교 통계는 프로그램이 계산합니다. AI는 사진을 해석하고, 주어진 후보를 선택하거나 계산 결과를 설명합니다. |
| **AI가 틀리거나 응답하지 않으면요?** | 영수증은 사용자가 확인 후 저장합니다. 추천은 후보를 검사하고 실패하면 기본 점수 순서를, 소비 분석은 숫자를 검사하고 실패하면 계산값에 따른 기본 설명을 제공합니다. |
| **데이터와 추천을 어디까지 믿을 수 있나요?** | 현재 시연에는 가데이터가 포함되어 있습니다. 영수증은 과거 구매 기록이므로 현재 판매가격·재고를 보장하지 않으며, 실제 이용자의 만족도 개선은 별도 검증이 필요합니다. |

**발표용 한 문장:** “여행WON해는 영수증 기록의 번거로움을 줄이고, 내 소비를 쉽게 이해하도록 돕고, 남은 예산에 맞는 구매 선택지를 이유와 함께 제안합니다.”
