# TravelBack AI 서비스 개편안 정리

핵심 콘셉트: AI 영수증 분석을 활용한 여행 가계부 및 위치 기반 상품 가격 비교 서비스

기존의 챗봇, ATM 비교, 나의 여행 페이지는 제외하고, AI 여행 가계부와 주변 상품 가격 비교 두 가지 기능을 중심으로 구성한다.

## 1. PAGE 1 — AI 여행 가계부

### ① 영수증 OCR 자동 등록

기존 가계부 기능을 유지하면서 영수증 OCR을 통합한다.

- 사용자가 영수증 사진을 업로드하면 AI가 매장명, 구매일, 상품명, 수량, 상품별 가격, 총 결제금액을 추출한다.
- 추출한 데이터를 자동으로 음식·쇼핑·교통·숙박·관광·기타 카테고리로 분류한다.
- 사용자가 인식 결과를 확인하고 수정한 뒤 가계부에 저장한다.
- 상품별 구매정보는 사용자의 동의를 받아 PAGE 2의 가격 비교 데이터로 활용한다.

### ③ 평균 소비 비교 — 신규 기능

도넛 차트 오른쪽에 다른 여행자의 평균 소비 비율과 비교하는 영역을 추가한다.

| 카테고리 | 나의 비율 | 평균 비율 | 차이 |
| --- | --- | --- | --- |
| 숙박 | 57% | 42% | +15%p |
| 쇼핑 | 20% | 15% | +5%p |
| 음식 | 12% | 18% | -6%p |
| 교통 | 6% | 12% | -6%p |
| 관광 | 5% | 10% | -5%p |
| 기타 | 0% | 3% | -3%p |

화면 설계용 가상 평균 데이터. %p는 소비 비율 간 차이를 나타낸다.

AI 분석 결과는 다음처럼 자연어로 제공할 수 있다.

AI 소비 분석

숙박 지출 비중이 비교 집단 평균보다 15%p 높고, 쇼핑은 5%p 높아요. 반면 음식과 교통은 각각 6%p 낮아요.

이번 여행은 다른 여행자보다 숙박과 쇼핑에 상대적으로 지출이 집중되어 있어요.

평균 산출 방식 제안

실제 서비스에서는 전체 여행자를 무작정 평균 내기보다, 같은 국가·도시에서 비슷한 기간 여행한 이용자들의 카테고리별 지출 비율을 평균 내는 것이 좋아.

MVP에서는 우선 가상 평균 데이터를 사용하고, 실제 영수증 데이터가 충분히 축적되면 유사 여행자 집단의 통계로 대체할 수 있어. 비교 표본이 부족하면 '평균'이라고 단정하지 않고 시연 데이터임을 표시해야 해.

### ④ 여행 예산 관리

기존 예산 사용률 기능을 유지한다.

### ⑤ 나의 영수증

지출 차트와 평균 비교 영역 아래에 '나의 영수증'을 배치한다.

등록된 영수증을 매장별로 확인할 수 있으며, 매장명·구매일·카테고리·금액 등을 표시한다. 기존 영수증 등록 내역을 그대로 활용하고, 환급 관리 기능을 유지하는 경우에만 관련 상태를 함께 표시한다.

## 2. PAGE 2 — 내 주변 상품 가격 비교

핵심 기능: 사용자가 상품을 검색하면 현재 위치 주변 매장에서 실제 구매한 영수증 기록을 바탕으로 가격을 비교한다.

| 단계 | 기능 |
| --- | --- |
| ① 상품 검색 | 예: 코카콜라 500ml 입력 |
| ② 현재 위치 확인 | 사용자 동의를 받아 위치 확인 |
| ③ 주변 매장 지도 | 상품 구매 기록이 있는 매장을 지도에 마커로 표시 |
| ④ 가격 비교 | 동일 상품의 매장별 최근 구매가격 비교 |
| ⑤ 가격 정보 확인 | 가격, 구매일, 매장 위치, 거리 표시 |

지도는 검색창 아래에 배치하고, 지도 아래에는 가격이 낮은 순서의 매장 목록을 보여준다.

예시:

| 매장 | 영수증 구매가격 | 거리 |
| --- | --- | --- |
| 마트 A | €1.80 | 도보 약 4분 |
| 마트 B | €2.10 | 도보 약 8분 |
| 마트 C | €2.50 | 도보 약 12분 |

가상 매장 데이터. 실제 서비스에서는 위치 API 및 매장 좌표를 통해 거리와 지도 마커를 계산해야 한다.

영수증에 기록된 금액은 과거 구매가격이므로 현재 판매가격이나 재고가 보장되지는 않는다는 점을 안내한다.

## 4. 개발 우선순위

| 우선순위 | 작업 |
| --- | --- |
| P0 | 기존 가계부와 영수증 OCR 통합 |
| P0 | OCR에서 상품별 이름·가격·수량 추출 |
| P0 | 상품명 정규화 및 매장별 가격 데이터 저장 |
| P0 | 상품 검색 및 주변 매장 지도 표시 |
| P1 | 매장별 영수증 기반 가격 비교 |
| P1 | 카테고리별 지출 평균 비교 |
| P1 | AI 소비패턴 요약 |
| P2 | 실제 사용자 데이터 기반 평균 고도화 |

현재 가장 중요한 기술적 변경은 기존 OCR이 추출하던 총 결제금액뿐 아니라 상품별 구매가격까지 추출하도록 확장하는 것이야.

## 5. 최종 서비스 소개

TravelBack AI — AI 기반 여행 소비 관리 및 상품 가격 비교 서비스

TravelBack AI는 여행자의 영수증을 AI가 자동 분석하여 가계부를 작성하고, 카테고리별 소비패턴을 시각화하는 서비스다.

사용자는 자신의 소비내역을 유사 여행자의 평균 지출과 비교해 소비 특성을 확인할 수 있다.

또한 영수증에서 수집한 상품별 구매가격을 활용해 현재 위치 주변 매장의 가격을 비교함으로써 합리적인 소비를 지원한다.

핵심 차별점: 개인의 영수증 기록을 다른 여행자에게 유용한 상품 가격정보로 연결하는 데이터 순환 구조.

이 개편에서는 PAGE 1의 AI 영수증 데이터가 PAGE 2의 가격 비교 기능을 만드는 핵심 자원이 된다는 점이 가장 중요해. 단순 가계부가 아니라, 사용자가 늘어날수록 비교 가능한 가격정보가 축적되는 서비스로 설계하는 거야.
